## Generation prompt

Use case: logo-brand. Asset type: production desktop application icon for Nimi Overtone, a music creation workspace. Create ONE standalone square PNG icon, exactly 1024 x 1024 pixels, with a truly transparent background. A bold, original smooth harmonic-wave emblem forming a recognizable rounded O: three flowing interleaved sound ribbons, balanced and compact. Cool cyan, rich cobalt blue, a small violet accent, matching a modern Nimi glass music workspace. Flat clean vector-like raster artwork, broad simple shapes, crisp anti-aliased edges, restrained smooth gradients, no grain and no photographic texture. Centered mark occupies about 78% of the canvas with even clear margins. Must remain highly legible at 32 px, good contrast in both pale and dark UI. No text, no initials, no musical staff, no headphone illustration, no app mockup, no border, no opaque square background, no giant drop shadow. Deliver only the icon. Prefer simple colors and efficient PNG encoding suitable for an icon asset below 512 KiB.
