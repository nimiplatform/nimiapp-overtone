# Nimi Overtone Nimi Listing Request

This document is a developer-submitted listing request. It is not an approval, release descriptor, permission grant, or install truth.

## Developer Runbook

```bash
pnpm install
pnpm dev -- --cdp-port 9222
pnpm run check
pnpm run pack
```

## Submission Inputs

- `nimi.app.yaml` declares app identity and requested API scopes.
- `.nimi/admission/submission.yaml` records publish-readiness commands and review inputs.
- `.nimi/admission/build-profile.yaml` records install, init, build, and lockfile policy.
- `dist/nimi-app-submission.json` is produced by `pnpm run pack` after a successful renderer build.

## Reviewer Boundary

Overtone offers authored inspiration prompts, protected AI text direction and lyrics assistance, and protected prompt-plus-lyrics music generation. Completed and decoded artifacts become append-only takes. Local audition includes trim, looping and playback speed, with explicit original or trimmed-WAV downloads. Text-based reinterpretation references the original prompt and lyrics only. Audio-reference remix and Realm publication remain unavailable.

Draft references and display preferences stay in app-owned browser storage; generated bytes and active jobs do not. User-requested downloads are ordinary file exports, separate from Realm publication.

Nimi Platform review owns final admission, release descriptors, ordinary-user visibility, install availability, and permission grants.

Completed music jobs may leave app-owned pending-import references with author submission snapshots when artifact loading fails. Recovery queries the same protected job and artifact; it does not resubmit generation. Audio/PCM and active jobs are not persisted. Writing consumes the protected cancellable text stream. Publication actions and the independent dev-preview entry have been removed. The project consumes published SDK/Kit packages; production preflight rejects local package links. No release or installed-runtime acceptance is claimed.
